# 检索与问答 Bad Case 模式库（学习笔记）

## 专有名词被同义改写冲掉

用户问缩写或论文名，改写工具改掉关键字导致 NO_HITS。缓解：改写保留专有名词与数字；先原查询再改写。

## 同义改写词法全灭

口语问题在词法通路零命中，向量通路可救。缓解：混合检索；评测集保留同义题。

## 近重复顶满 top-k

多段相似说明占满候选，真正关键句靠后。缓解：去重、加大 k 再 rerank、整理源文档。

## 切分切断关键句

答案跨边界，单 chunk 不完整。缓解：overlap；或按标题切。

## 误检索闲聊

问候语触发 search。缓解：系统提示 + 工具描述 + 评测扣分。

## 拒答却堆引用

看起来很博学，实则误导。缓解：拒答路径限制引用。

## 外推

片段只支持 A，答案写成 A+B。缓解：忠实度抽查；生成提示强调「只依据片段」。

## 指标饱和幻觉

小库全 1.00 被讲成已解决检索。缓解：报告写清规模；补充分题型与延迟。

## 记录模板

输入 / 期望 / 实际 / 根因 / 修复 / 是否已回归。每条可复现。宁可少而真，不要空泛「有时不好」。

## 与产品体验

Bad case 修复后，用同一输入在 CLI 与 API 各打一遍，确认服务层没有另开一套未打补丁的逻辑。
